Online quiz
1. Fitur baru LMS dimana siswa bisa jawab soal quiz MCQ atau fill in the blanks simpel buat quick assesment atau simpel review/quiz
Cara kerja:
Sisi admin (pembuatan quiz)
1. Admin ke tab baru di sidebar namanya quiz
2. Disana akan ada page quiz dengan beberapa card (jika sudah ada beberapa quiz) yg masing2 card isinya ada info seperti nama quiz, tanggal kapan terakhir di modifikasi, berapa soal, dll.
3. Kalau kita misal pencet salah satu card, akan ada tampilan edit quiz yg mirip di google form, bisa tambah soal dengan toolbar + di samping, bisa isi soalnya, dll
4. Di card soal, kita bisa cek mau pilih MCQ atau quiz
5. Kalau MCQ, berarti kita harus isi 4 pilihan ganda, terus dibawah ada tombol select correct answer dan setelah itu bisa pencet pilihan mana yg correct
6. Kalau quiz, berarti tinggal pencet select correct answer terus kita bisa isi jawaban kuncinya (Ketentuan: jawaban siswa gak harus sama persis dengan kunci asli, misal ada spasi ekstra atau huruf depan kapital masih ditoleril, yang penting kata/huruf/frasaya sama)
7. Layout again seperti google form, di topbar utama ada beberapa fitur seperti ganti nama quiz, cek responden, ada tombol Publish, set due date, Mapel, materi, dll.'
8. Kalau misal mau buat quiz baru akan ada tombol Quiz baru di main page quiz mungkin di topbar pojok kanan, nanti akan dialihkan ke page quiz baru yg dimana kita bisa buat soalnya, setting judul, dll.

Sisi siswa:
1. Siswa dapat tombol baru di sidebar yaitu Quiz
2. Disana akan ada dashboard Quiz seperti panel quiz yg ada due datenya (sortir berdasarkan deadline)
3. Dibawah panel deadline akan ada panel select quiz, akan ada dropdown mau pilih quiz apa dan tombol OK atau semiripnya
4. Nanti dialihkan ke jawab quiz dimana kita bisa pilih MCQnya, atau jawab esai nya, dll. Dibawah akan ada tombol submit
5. Kalau sudah submit, nanti akan ada page singkat isinya Score autograde kamu berapa, Rumusnya (Total benar / total soal) x 100, namun dibulatkan kebawah jadi tidak ada desimal. Yg agak besar nilainya karena pagenya lumayan kosong setelah submit
6. Terus setelah nilainya juga ada tombol view quiz, kita bisa lihat salah dimana, benar dimana, jika salah, maka ada page 'correct answer'
7. Kalau sudah, dibawah atau ditopbar akan ada tombol return to quiz atau balik ke halaman dashboard quiz utama
8. Halaman quiz juga ada log quiz kita, bisa kita pencet juga kalau mau liat hasilnya yg dulu
